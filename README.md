## ✦ What is CodeVisualizer?

**CodeVisualizer** is an interactive learning platform that transforms the way you understand algorithms and data structures. Instead of staring at static code, watch each operation unfold visually — with full step-by-step control, multi-language code views, and an AI chatbot to explain it all in plain English.

Whether you're a student prepping for interviews or a developer brushing up on fundamentals, CodeVisualizer makes the invisible visible.

## 🚀 Getting Started

### 1 · Clone the Repository

```bash
git clone https://github.com/ankit-rawat-99/CodeVisualizer.git
cd CodeVisualizer
```

### 2 · Install Dependencies

```bash
# Backend
cd backend && npm install

# Frontend
cd ../frontend && npm install
```

### 3 · Run the Project

```bash
# Terminal 1 — Start backend
cd backend
node server.js

# Terminal 2 — Start frontend
cd frontend
npm run dev
```

### 4 · Open in Browser

```
http://localhost:5173
```

## 🎯 Project Goal

Most algorithm learning is passive — you read code, you forget code. **CodeVisualizer** flips the model.

By making every swap, traversal, and comparison *visible*, the platform helps learners build true intuition rather than surface-level memorization. The result? Better understanding, better debugging, better problem-solving.
